# 谁在偷跑 —— 隐私政策

**生效日期：2026-11-20**

**联系邮箱：wangjinchao@castianta.com**

「谁在偷跑」（下称「本 App」）是一款手机后台行为审计工具。它读系统的用量事件，告诉你哪些 App 在你没碰手机的时候自己动了起来。

本政策说明本 App **收集什么**、**收集多少**、**存在哪里**、**会不会传出去**，以及你有哪些权利。

一句话先说清楚：**本 App 没有联网权限，不含任何第三方统计或广告 SDK，采集到的数据全部只留在你自己的手机里，永远不会上传。**

---

## 一、我们收集什么

本 App 声明并使用以下系统权限，通过下列系统 API 读取数据。表格里每一行都能在代码里对上号。

| # | 收集的数据 | 使用的系统 API | 用来做什么 | 是否上传 |
|---|---|---|---|---|
| 1 | 各 App 的前台时长、后台时长 | `UsageStatsManager.queryUsageStats()` → `UsageStats.getTotalTimeInForeground()` / `getTotalTimeInBackground()` | 计算「后台驻留」时长，算偷跑指数 | 否 |
| 2 | 活动事件：某个 App 何时被启动到前台、是否抢了焦点、是否在息屏状态下启动 | `UsageStatsManager.queryEvents()` → `UsageEvents.Event`（事件类型 `ACTIVITY_STARTED` / `ACTIVITY_RESUMED` / `ACTIVITY_PAUSED` / `ACTIVITY_STOPPED` / `SCREEN_INTERACTIVE` / `SCREEN_NON_INTERACTIVE` / `USER_PRESENT` / `USER_UNLOCKED`） | 判定「息屏启动」「抢占焦点」这两类硬证据 | 否 |
| 3 | 屏幕亮灭事件 | 同上，`SCREEN_INTERACTIVE` / `SCREEN_NON_INTERACTIVE` | 判断事件发生时屏幕是开还是关 | 否 |
| 4 | 分 App 的流量消耗（移动 + Wi-Fi 合计，部分 ROM 读不到） | `NetworkStatsManager.queryStatsForUid(uid, begin, end)` | 计算「流量偷跑」 | 否 |
| 5 | 各 App 的**权限声明与授予状态**，尤其是后台定位权限 `ACCESS_BACKGROUND_LOCATION` | `PackageManager.getPackageInfo(package, PackageManager.GET_PERMISSIONS)`、`PackageManager.checkPermission()` | 标出哪些 App 持有「始终允许」的后台定位权限 | 否 |
| 6 | 本 App 自己有没有拿到「使用情况访问权限」 | `AppOpsManager.unsafeCheckOpNoThrow("android:get_usage_stats", …)` | 判断能不能开始采集 | 否 |
| 7 | 本机健康状态：电量、是否充电、存储余量、温度状态 | `BatteryManager`、`StatFs`、`PowerManager.getCurrentThermalStatus()` | 本机健康自检（iOS 版的主要功能） | 否 |
| 8 | 设备指纹（仅在你主动使用「绑定设备」时才有意义） | `Settings.Secure.ANDROID_ID` 与机型信息拼接后做 SHA-256 | 让授权码绑定到这台设备，避免一个码被到处用 | 否 |

关于第 5 条，需要说得非常清楚：

> **本 App 只读取「某个 App 是否申请了后台定位权限、这个权限当前是否被授予」这个权限状态本身。**
> **本 App 不读取任何位置坐标，不接收任何定位数据，也没有任何途径能拿到别的 App 的定位记录。**
> 在 Android 上，公开 API 并不提供读取其它 App 定位记录的能力。
> 所以「定位嫌疑」这一项的含义是：**这个 App 具备在后台持续定位的能力，风险面比没有这类权限的 App 更大。持有权限不等于它定位过。**

关于第 4 条：部分厂商 ROM 与系统版本不允许普通应用读取分应用流量。读不到的时候，本 App **不会用 0 冒充「没有流量」**，而是把这一整条维度标记为「读不到」并从评分中剔除。

## 二、我们不收集什么

以下内容本 App **一律不采集、不读取、不存储**：

- **任何个人内容**：短信、聊天记录、通话记录、邮件、剪贴板内容、相册与照片、文件、浏览器历史、剪贴板、桌面内容。
- **任何账号信息**：登录态、账号密码、Cookie、令牌、通讯录、账号列表。
- **任何位置坐标**：不调用定位 API，不请求定位权限，不接收经纬度。
- **任何麦克风、摄像头、传感器数据**。
- **任何应用的内容**：本 App 只看系统记录的用量事件和权限状态，从不读取其它 App 的内部数据、数据库或缓存。
- **你的通讯录、短信、通知内容**。
- **广告标识符**：不采集设备 ID 用于广告或画像。
- **不收集儿童数据**（见第七节）。

一句话：**本 App 只看「App 什么时候动、在前台还是在后台、花了多少流量、申请了什么权限」，不看 App 里面有什么。**

## 三、数据是否上传

**不上传。任何数据都不上传。**

具体来说：

- 本 App **没有声明 `android.permission.INTERNET` 权限**，在系统层面就不具备访问网络的能力。
- 本 App **不含任何第三方统计、广告、崩溃上报 SDK**。依赖清单里只有 `cryptography`（授权码验签）、`shared_preferences`（本地设置）、`intl`（格式化）、`path_provider`（导出文件路径）四个纯本地库。
- 不存在「先收集再上传」的中间环节，也不存在崩溃日志远程上报。
- 授权码的激活与校验是**纯本地验签**：App 内置 Ed25519 公钥，拿到授权码后在本机验签，不向任何服务器发起请求，不需要注册账号。

## 四、数据存储位置

**全部只存在你的设备本地。**

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 审计结果（各 App 时长、证据、流量、权限状态） | 内存 | 每次审计重新采集，App 进程结束即消失，不落盘 |
| 白名单、审计时间范围、告警间隔、上次扫描时间 | 系统 `SharedPreferences` | 本 App 私有目录，其它 App 读不到 |
| 授权码与设备指纹 | 系统 `SharedPreferences` | 本 App 私有目录；「解除授权」会立刻删除 |
| 导出的 CSV 报告 | App 文档目录（`getApplicationDocumentsDirectory()`） | 只有你主动点「导出」才会写文件；文件留在本机，分享与否由你决定 |

卸载本 App 会一并删除以上全部内容。

## 五、各项权限的用途

| 权限 | 用途 | 为什么必须要 | 不给会怎样 |
|---|---|---|---|
| `android.permission.PACKAGE_USAGE_STATS`（使用情况访问权限） | 读各 App 的前台/后台时长、活动事件、屏幕亮灭 | 这是本 App 的立身之本。**没有它就看不到任何「谁在偷跑」**，因为这些事实只存在于系统的用量事件流里 | 首页显示一张引导卡，指引你到系统设置里手动开启；在你开启之前，本 App 不做任何采集 |
| `android.permission.QUERY_ALL_PACKAGES` | 看到设备上安装的全部 App | Android 11 起默认只能看到一部分可见 App。不声明这个权限就等于漏掉一半在后台活动的 App | 榜单会严重不全，看到的 App 只是实际的一小部分 |
| `android.permission.READ_NETWORK_STATE` | 读分 App 的流量消耗 | 不声明就完全无法计算「流量偷跑」这一项 | 流量维度整个消失，其余维度照常工作 |
| `android.permission.POST_NOTIFICATIONS` | 发本地告警通知（Android 13+） | 定期审计发现新的息屏启动/抢焦点时提醒你 | 不弹通知，其余功能不受影响 |
| `android.permission.RECEIVE_BOOT_COMPLETED` | 开机后重排审计闹钟 | 否则重启后告警计划就断了 | 开机后需要手动重开一次告警开关 |

**「使用情况访问权限」是特殊权限，系统不允许 App 自行弹出授权框**，必须由你手动到系统设置里打开。路径是：

> 设置 → 应用 → 特殊应用权限 → 使用情况访问权限 → 找到「谁在偷跑」→ 打开

本 App 只负责跳转到这个设置页，**替你勾选的操作一律由你自己完成**。

## 六、权限被撤销后会发生什么

你可以随时在系统设置里撤销本 App 的任何权限。本 App 会在下次审计时立即感知到，并做出如下反应：

- **撤销「使用情况访问权限」**：审计无法进行。本 App 首页会重新显示授权引导卡，**不做任何采集**。已经拿到的审计结果只在内存里，App 关闭后即消失。
- **撤销「通知」权限**：不再弹告警通知，审计本身照常运行。
- **系统回收流量读取能力（部分 ROM 的限制）**：流量维度从评分中剔除，并在界面上如实标注「读不到」，**不会显示成 0 流量**。
- **卸载 App**：所有本地数据（含白名单、授权码、导出的 CSV 所在目录）一并清除。

本 App **不会因为权限被撤销而崩溃或卡死** —— 采集链路上的每一步都做了失败兜底，任何一步取不到数据都只是少一路信号，不会让整次审计失败。

## 七、用户权利

本 App 不收集你的数据，所以「删除数据」这件事在你这边随时可以完成，不依赖任何服务器或客服：

| 你想做的事 | 怎么做 |
|---|---|
| **查看本 App 掌握的全部数据** | 首页「偷跑榜」与各 App 详情页，展示了全部采集项：时长、次数、流量、权限状态、每一条证据的时间和描述 |
| **导出数据** | 首页右上角分享图标 → 导出 CSV，文件写到 App 文档目录。CSV 包含：应用名、包名、偷跑指数、等级、自启次数、息屏启动次数、抢焦点次数、前台时长（分钟）、后台时长（分钟）、流量（MB）、是否有后台定位权限、证据条数 |
| **把某个 App 移出视野** | App 详情页 → 「加进白名单（别再提醒我）」。白名单只是本机的一个标记，不影响系统里该 App 的任何权限 |
| **删除授权** | 设置页 → 「解除授权」。授权码与设备指纹立刻从本机删除，可随时重新输入授权码激活 |
| **删除白名单** | 设置页 → 白名单列表 → 「移出白名单」 |
| **停止一切采集** | 撤销「使用情况访问权限」，或直接卸载 App |
| **撤回导出的文件** | CSV 写在你的设备上，删掉即可，App 不会保留副本 |

## 八、儿童隐私

本 App **不面向儿童设计**，也**不故意收集任何儿童的个人信息**。

本 App 采集的内容全部是系统层面的 App 使用统计与权限状态，**不包含任何可识别特定自然人的内容**：没有账号、没有通讯录、没有位置坐标、没有个人内容、没有设备标识符用于画像。

如果你是儿童用户的监护人，可以随时卸载本 App，或在系统设置里撤销「使用情况访问权限」以停止全部采集。卸载即彻底删除所有本地数据。

## 九、iOS 版本的说明

iOS 与 Android 的能力边界不同，这里单独讲清楚，避免误解：

- 苹果**不允许**第三方 App 读取其它 App 的使用情况。这是系统级的隐私设计，**没有公开 API，也没有可靠的绕过办法**。
- 因此 **iOS 版不提供** Android 那套后台行为审计。它不会假装能做到。
- iOS 版只提供三样确实能做的事：
  1. **本机健康自检**：电量、充电状态、存储余量、温度状态。
  2. **系统自带路径的指引**：教你自己走「设置 → 屏幕使用时间 → 查看 App 使用时间」、「设置 → 隐私与安全性 → 定位服务」逐个改成「使用期间」、「设置 → 通用 → 后台 App 刷新」这些系统路径。
  3. **一份可复制的隐私自查清单**：按购物类、短视频、地图出行、资讯推送、输入法、安全管家、金融支付等类别生成清单，你可以复制出来照着改。
- iOS 版同样**没有联网权限、不上传任何数据**。
- 目前提供的 iOS 构建产物是**未签名 IPA**，需要自行签名后才能安装到设备上。

## 十、授权码与设备指纹

如果你购买授权，本 App 会处理两类与支付相关的数据：

- **授权码**：你输入的一段字符串，本 App 在本机用内置公钥验签。它不包含你的姓名、邮箱或支付信息。
- **设备指纹**：`ANDROID_ID` 与机型信息拼接后的 SHA-256 值，**只在本机计算、本机比对、从不上传**。它存在的唯一目的是让「绑定设备」的授权码不能在一台机器之外使用。

App 不会为了「验证你是你」而要求注册账号、绑定手机号或绑定邮箱。
